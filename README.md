# 📮 Website Kotak Saran Digital

![Visitors](https://visitor-badge.laobi.icu/badge?page_id=hendragunadie.kotakSaran)

Selamat datang di repositori **Kotak Saran Digital**!  
Proyek ini merupakan sebuah aplikasi web sederhana yang memungkinkan pengunjung memberikan **saran, kritik, atau masukan** secara langsung melalui sebuah formulir online.  

Semua data saran yang masuk akan secara otomatis **disimpan ke dalam file spreadsheet/Excel**, sehingga mudah untuk diolah, dibaca, atau diarsipkan oleh pemilik website atau pengelola organisasi.

## 🎯 Tujuan Proyek

Tujuan utama dari pembuatan Kotak Saran ini adalah:

- Menyediakan cara modern dan efisien untuk mengumpulkan masukan dari pengguna atau pengunjung.
- Mengganti metode kotak saran fisik dengan versi digital yang lebih praktis dan terarsip dengan baik.
- Melatih penggunaan teknologi web statis (HTML, CSS) yang terhubung dengan Google Spreadsheet/Excel.

---

## 🧰 Teknologi yang Digunakan

Proyek ini dibangun dengan teknologi sederhana namun fungsional:

- **HTML** – untuk membuat struktur formulir masukan.
- **CSS** – untuk mempercantik tampilan antarmuka.
- **Google Apps Script / FormSubmit / SheetDB** – untuk menyimpan data ke spreadsheet secara otomatis.
- **GitHub Pages** – untuk hosting gratis dan mudah diakses oleh siapa saja.

Tidak ada framework berat atau backend kompleks, sehingga sangat ringan dan cepat.

---

## 📋 Fitur Aplikasi

- 📩 Formulir saran yang mudah digunakan
- ✅ Validasi input sederhana (nama dan pesan)
- 💾 Penyimpanan otomatis ke Google Spreadsheet/Excel
- 🌐 Dapat diakses di mana saja dan kapan saja
- 💡 Cocok untuk sekolah, organisasi, UKM, acara, dan keperluan internal
